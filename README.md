# 问证智学

面向初中探究式学习和科学普及实践的“过程证据 + 智能反馈”平台 Demo。作品通过可运行的学生端和教师端，展示问题提出、假设形成、证据分析、CER 论证、反思迁移和教学干预的完整闭环。

## 内置任务

- 怎样让午后的教室更凉快：比较降温效果、成本和证据可靠度。
- 城市热岛是如何形成的：比较不同地表与时段的温度，解释热岛机制。
- 校园池塘水质为何发生变化：分析营养盐、藻类、水温和溶解氧的关系。

三个任务分别保存步骤、输入、假设和证据选择，切换任务不会覆盖已有内容。

## 运行方式

电脑已安装 Node.js 时，在本目录运行：

```powershell
node server.js
```

浏览器打开 `http://127.0.0.1:4173`。也可以直接双击 `index.html`，核心功能仍可使用。

## 演示路线（建议 5 分钟）

1. 从“学习总览”的任务库选择一个探究主题。
2. 在第 3 步比较图表、多维指标和证据可靠度。
3. 在第 4 步选择两条以上证据并完成 CER 论证。
4. 使用 AI 学伴的“检查推理”，强调 AI 只追问、不代答。
5. 打开“证据档案”，展示过程记录与贡献边界。
6. 切换教师角色，展示班级热力图、共性困难与分层追问。

## 功能完成度

- 学生端：三项任务、五步探究、数据图表、CER 论证、反思、独立保存、档案导出。
- AI 学伴：比较证据、检查推理、发现局限及开放式追问。
- 教师端：班级进度、证据链分布、共性困难、过程快照、分层追问。
- 合规：本地存储、模拟数据说明、AI 使用边界和参赛披露入口。
- 响应式：桌面、平板和手机均可浏览。

## 作品定位

本版本是前端交互 Demo。AI 学伴采用本地规则回复，以便离线稳定演示；真实部署可接入经学校审核的模型服务。所有姓名与数据均为模拟，不含真实学生隐私。
