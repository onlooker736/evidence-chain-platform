# evidence-chain-platform

#### 介绍
证据链探究学习平台||大学生数组媒体科技作品竞赛
   面向初中探究式学习和科学普及实践的「过程证据 + 智能反馈」平台 Demo。作品包含可运行的学生端和教师端，完整覆盖问题提出、假设形成、证据分析、CER论证、反思迁移、教学干预的探究闭环。
内置三项探究任务：
- 怎样让午后的教室更凉快：比较降温效果、成本和证据可靠度
- 城市热岛是如何形成的：比较不同地表与时段的温度，解释热岛机制
- 校园池塘水质为何发生变化：分析营养盐、藻类、水温和溶解氧的关系
三个任务独立保存填写内容，切换任务不会覆盖已有记录。

#### 软件架构
软件架构说明
本项目为前端静态交互Demo，页面逻辑、图表渲染、本地存储全部在浏览器端完成；AI学伴采用本地规则回复，支持离线演示。
可选配套 Node.js 服务用于本地部署，正式版本可对接经学校审核的大模型服务。
> 数据说明：全部案例、观测数据为模拟数据，不包含学生真实隐私。

#### 安装教程

1. 最简方案（推荐评审使用）：无需安装依赖，直接下载仓库文件
2. 若使用本地服务端：本地安装 Node.js 环境
3. 在项目根目录打开终端，执行 `node server.js`

#### 使用说明
1. 本地快速预览：直接打开 `dist/index.html`，浏览器即可运行全部核心功能
2. 服务方式访问：启动服务后，浏览器访问 `http://127.0.0.1:4173`
3. 答辩演示路线（5分钟版本）
    - 在任务库选择探究主题，完成五步探究流程
    - 选取≥2条证据，完成CER科学论证，使用AI学伴进行推理检查（AI仅追问、不代答）
    - 查看证据档案，切换教师端查看班级热力图、共性困难与分层追问方案
